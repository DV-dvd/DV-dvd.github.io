Autonomous Risk-Modeling Agent自研风控建模智能体

A self-built modeling agent, proven on a real consumer-credit model自研建模智能体，已落地到真实消费信贷模型

Designed an agent that owns the full credit-model lifecycle — a human-in-the-loop system that cleanly separates deterministic computation from LLM reasoning, so the agent decides while every number stays reproducible.设计一个掌管信贷模型全生命周期的智能体：人在环中的架构，把确定性计算与大模型推理彻底解耦——智能体负责决策，每个数字依然可复现。

  • Orchestrates an 8-stage pipeline (sample analysis → split → feature selection → training → export → acceptance) gated by 3 human checkpoints.编排八阶段流水线（样本分析 → 切分 → 特征筛选 → 训练 → 导出 → 验收），由 3 个人工检查点把关。
  • The agent reasons over monthly statistics to choose Train/Val/OOT splits and the tuning strategy, selecting among 4 regimes (time-decay weighting, rolling-window ensembling, Focal Loss and standard).智能体基于月度统计自主推理 Train/Val/OOT 切分与调参策略，在四种方案间择优（时间衰减加权、滚动窗口集成、Focal Loss、标准等权）。
